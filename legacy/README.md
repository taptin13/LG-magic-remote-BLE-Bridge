# Legacy

Không dùng cho stack hiện tại. Giữ để đối chiếu / khôi phục ý tưởng.

| Thư mục | Mô tả |
|---|---|
| `MagicRemoteStudio-v1.0/` | Studio Mac + `esp32-legacy-jw` + `lg-magic-master` |
| `MRDongleConfig/` | App cấu hình HID dongle qua USB serial |
| `esp32-hid-dongle/` | Firmware BLE HID → Mac (Arduino) |
| `esp32-ble-bridge/` | GATT bridge Arduino sớm |
| `esp32-proxy/` | Proxy Arduino (trước ESP-IDF / NimBLE) |
| `run-mrdongle-config.sh` | Script build/run MRDongleConfig (cũ) |

**Active:** [`../MagicRemoteBLE`](../MagicRemoteBLE) + [`../esp32-proxy-idf`](../esp32-proxy-idf).
